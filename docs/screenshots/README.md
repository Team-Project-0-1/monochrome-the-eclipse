# 스크린샷 디렉토리

루트 `README.md`가 이 폴더의 이미지를 참조합니다. 아래 3개는 자동 캡처로 채워졌고, `event.png`는 게임 플레이가 필요해 선택 확장으로 남겨 둡니다.

## 확보 완료 (README가 현재 참조)

| 파일명 | 컷 내용 | README 위치 |
|---|---|---|
| `combat-hero.png` | 전투 중 — 동전·적 의도·예측 레일·일식 배경이 한 화면에 | 상단 메인 히어로 |
| `character-select.png` | 캐릭터 선택 — 4명 라인업과 상세 패널 | 갤러리 1 |
| `exploration.png` | 탐험 — 벙커 외곽 노드 선택과 런 진행도 | 갤러리 2 |

## 선택 확장

| 파일명 | 컷 내용 | 비고 |
|---|---|---|
| `event.png` | 이벤트 — 분기 선택과 결과 패널 | 전투를 클리어하고 이벤트 노드에 진입해야 나오는 화면. 캡처해 이 폴더에 넣고, README "스크린샷" 표에 열을 하나 더하면 갤러리 3번째로 표시됩니다. |

## 권장 사양

- **포맷**: PNG
- **비율**: 16:9 데스크탑 뷰 (위 3컷은 1600×900 headless 캡처)
- **캡처 방법**: `npm run dev` 실행 후 데스크탑 폭(≥1280px)에서 캡처. 메뉴·캐릭터 선택의 튜토리얼 코치마크는 끈 상태를 권장.

> 임시 디버그 스크린샷(커밋 금지)과 달리, 이 제품 쇼케이스 이미지는 커밋 대상입니다.
